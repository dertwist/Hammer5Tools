# Legacy Python application

The previous PySide6 application, bridge, automation and Python regression tests live in `Hammer5ToolsGUI/`. Its package structure is unchanged. From this folder, run `python Hammer5ToolsGUI/gui/main.py` or `python -m pytest Hammer5ToolsGUI/Tests`. `src/` and `keyvalues3/` retain earlier local Python sources.

The managed application lives in `../GUI/`. The C# Core and native launcher remain outside this folder.
